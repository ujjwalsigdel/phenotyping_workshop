# Mistakes Log

Read this file at the start of every task in this domain (see SKILL.md § 0).
Append a new entry any time a factual claim you made turns out to be wrong,
unverified-but-stated-as-fact, or based on a bad source. Newest entries at
the top.

Format: 
YYYY-MM-DD — <short title>

What happened: <the claim/action and why it was wrong>
Correction / feedback: <what the user said, or what the right answer was>
Rule going forward: <one-line, actionable rule to prevent recurrence>


---

### Example entry (delete once real entries exist)
**What happened:** Stated a specific Fv/Fm threshold for "stressed" plants
without checking a source, presented as settled fact.
**Correction / feedback:** User pointed out the threshold is species- and
protocol-dependent and asked for a citation.
**Rule going forward:** Never state a numeric physiological threshold without
a Tier-1 citation; if species/protocol isn't specified, ask before answering.
