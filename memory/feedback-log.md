# Feedback Log

Read this file at the start of every task in this domain (see SKILL.md § 0).
This is for standing preferences and working instructions the user gives —
things about *how* they want this skill to work, as opposed to one-off
factual corrections (those go in `mistakes-log.md`). Newest entries at the
top.

Format:
YYYY-MM-DD — <short title>

Feedback: <what the user said>
Rule going forward: <one-line, actionable rule>
