# Source Tiers for Plant Phenotyping

Read this before searching. Rank every source you find into one of these
tiers, and tell the user the tier if there's any doubt about reliability.

## Tier 1 — trust these first

**Peer-reviewed journals (phenotyping-relevant):**
- Plant Phenomics (AAAS/Nanjing Agricultural University)
- Plant Methods (BMC/Springer)
- Journal of Experimental Botany
- in silico Plants
- Frontiers in Plant Science (phenotyping/technical sections)
- Plant, Cell & Environment
- New Phytologist
- Functional Plant Biology
- Remote Sensing (MDPI) — for imaging/sensing methodology specifically
- Computers and Electronics in Agriculture — for HTP hardware/software methods

**Standards bodies / consortia (official documentation):**
- IPPN — International Plant Phenotyping Network
- MIAPPE — Minimum Information About a Plant Phenotyping Experiment (standard)
- EPPN2020 — European Plant Phenotyping Network
- ELIXIR / plant data standards groups

**Government & public research institutions (official pages/publications):**
- USDA-ARS, USDA NIFA
- INRAE (France)
- Wageningen University & Research — Plant Sciences / phenotyping groups
- IPK Gatersleben
- John Innes Centre (JIC)
- Australian Plant Phenomics Facility (APPF)
- CGIAR centers (e.g. CIMMYT, IRRI) for crop phenotyping in breeding contexts
- Danforth Plant Science Center, Carnegie Institution for Science

These outrank everything else. If a claim is only supported by sources below
Tier 1, say so and flag confidence as "emerging" or "unclear" rather than
presenting it as settled.

## Tier 2 — usable, but flag it

- Preprints (bioRxiv, etc.) — **not yet peer-reviewed**, always say so
- Conference proceedings (e.g. from plant phenomics symposia)
- PhD/Masters theses
- Reputable review articles that synthesize but aren't primary research
- Official vendor technical documentation (e.g. a camera/sensor manufacturer's
  spec sheet) — fine for hardware specs, **not** for scientific claims about
  what those specs mean biologically

## Tier 3 — background only, never for specific claims

- Wikipedia — fine for a quick orientation/definition, never cite as the
  source for a specific number or protocol
- Blog posts, marketing pages, forum posts
- General news coverage of a study (go find the actual paper instead)

**Rule:** Tier 3 material can help you find better search terms or point you
toward a real study, but it should never be the last stop for a factual
claim, and should never be the source you actually cite to the user.

## Search tips specific to this domain

- Search terms that work well: the trait/method name + "phenotyping",
  "high-throughput phenotyping", "HTP", the platform name (e.g. "LemnaTec",
  "PhenoArch", "Scanalyzer"), or the standard name ("MIAPPE").
- Prefer fetching the actual paper/page over trusting a search snippet —
  snippets truncate methodology and units, which is exactly where phenotyping
  claims go wrong (e.g. per-plant vs per-plot, fresh vs dry biomass).
- If a claim depends on units, growth stage, species, or environment
  (glasshouse vs field), and the source doesn't specify — that's a gap. Ask
  or flag it, don't assume the "usual" convention.
