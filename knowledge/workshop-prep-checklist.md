# PlantCV Geospatial Workshop — Prep Checklist

**Event:** PlantCV Geospatial Workshop
**Date:** 2026-09-17
**Location:** Donald Danforth Plant Science Center, St. Louis, MO
**Format:** Morning — PlantCV fundamentals. Afternoon — guided geospatial data
analysis walkthroughs. Extended lunch includes an optional walking tour with
the Danforth Center's Director of Phenotyping.

## Bring

- [ ] Laptop + charger
- [ ] Mobile phone (capable of taking pictures) + charger
- [ ] Comfortable closed-toed shoes (required if joining the lunchtime tour)

## Software — install before arriving

The email is explicit: if you show up without this installed, there's no
guarantee of time or help to do it on-site.

- [ ] Install **PlantCV** (conda-forge recommended)
- [ ] Install **PlantCV-Geospatial** add-on
- [ ] Verify both import correctly in a Python session

**Note:** As of this writing, PlantCV has an official conda-forge package;
PlantCV-Geospatial does not (only distributed via PyPI/GitHub) — install it
with pip inside the same conda environment. See install commands and status
in this session's log / ask the assistant to re-run `conda env list` /
`python -c "import plantcv, plantcv.geospatial"` to confirm.

- [ ] If your institution's security software blocks the install, contact
      IT **now**, not the morning of the workshop.
